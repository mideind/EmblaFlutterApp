# API keys

The Embla client reads its API keys from `lib/keys.dart`, which is generated by
`gen_keys.sh` from the key files in this directory. Both the key files and the
generated Dart file are gitignored and must never be checked into version
control.

Each key file contains a single API key (trailing whitespace and newlines are
stripped). All of them are optional: a missing file yields an empty string for
the corresponding constant, and the feature that needs it is simply unavailable.

| File | Dart constant | Read via (`lib/util.dart`) | Used for |
|---|---|---|---|
| `server.key` | `serverAPIKey` | `readServerAPIKey()` | Miðeind Ratatoskur server (ASR, TTS, Greynir queries, Hreimur) |
| `openai.key` | `openAIAPIKey` | `readOpenAIAPIKey()` | OpenAI (default LLM provider) |
| `elevenlabs.key` | `elevenLabsAPIKey` | `readElevenLabsAPIKey()` | ElevenLabs speech synthesis (optional TTS provider) |
| `anthropic.key` | `anthropicAPIKey` | `readAnthropicAPIKey()` | Anthropic (alternative LLM provider) |

Generate `lib/keys.dart` after adding or changing any key file:

```bash
bash keys/gen_keys.sh
```

Note that keys embedded in the app binary are only acceptable for internal
development builds. Store builds must obtain vendor keys via a server-side
proxy.
